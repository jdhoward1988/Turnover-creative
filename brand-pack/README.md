# The Turnover Creative — Brand Pack (2027)

Editable Adobe Express templates in the three brand directions, built for growing
followers among lifters and clubs. Sign-off on every page: **@theturnovercreative**.

| Express document | Size | Pages |
|---|---|---|
| Feed Posts 4x5 | 1080 × 1350 | 9 — A1 Feature, A2 Result, A3 Quote · B1 Hype, B2 Schedule, B3 PR · C1 Milestone, C2 Archive, C3 Member |
| Stories & Reel Covers 9x16 | 1080 × 1920 | 6 — one story + one reel cover per direction |
| Posters 11x17 | 3300 × 5100 (300 dpi) | 3 — Meet poster (A), Open platform (B), Club open day (C) |
| Brand Guide | 1920 × 1080 | 4 — How to use it, then one sheet per direction |

## Directions

- **A · Platform Journal** — results, meet coverage, features. Newsprint `#F2EFE8`, ink `#111111`,
  chalk `#C9C6BF` (rules only), signal red `#B5281F` (results only). Instrument Serif, IBM Plex Sans, IBM Plex Mono.
- **B · Warm-Up Room** — sessions, schedules, PRs. Black `#0E0E0E`, paper `#EDEDE8`, pink `#FF48B0`,
  blue `#0047BB`. Archivo Condensed Black, IBM Plex Mono.
- **C · Club Heritage** — club history, milestones, members. Green `#1F3A2E`, cream `#EDE6D6`,
  gold `#C9A46A`, oxblood `#6B1E1E`. Instrument Serif Italic, Graduate, IBM Plex Sans.

## Using the templates in Express

1. Photo frames are grey/brown placeholders labelled with the treatment (e.g. "PHOTOCOPY B&W").
   Select one → **Replace** → pick your own photo. Use only your own photography.
2. Text is live: click and type. Placeholder copy ("Meet Name", "Lifter Name", "Club Name") is meant to be replaced.
3. Stories: keep text between 250 px and 1580 px from the top (Instagram UI covers the rest).
4. Reel covers: keep the title inside the centre band — the profile grid crops to 3:4.

## Files

- `build.py` — generator. Edit the tokens or copy at the top/in each page, then `python3 build.py`.
- `express/*.html` — the HTML each Express document was imported from.
- `previews/` — PNG renders of every page (rendered with the open-source versions of the brand fonts).
